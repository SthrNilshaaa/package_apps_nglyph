# package_apps_nglyph
The New Nothing Phone 1 Glyph Manager 

# Setting up Glyph Manger
To build Glyph Manager you have to build the package in your device tree.
```bash
    # Glyph Manager
    PRODUCT_PACKAGES += \
        GlyphManager
```
